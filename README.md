# 에이전트 관리 콘솔

한 화면에서 AI 콘솔(claude, ollama 등) 여러 개를 만들고 전환하는 윈도우 앱.
tkinter로 만들었다.

## 방식

각 콘솔을 `conhost` 독립 창으로 띄우되, 관리창에 오너(owner)로 종속시켜
오른쪽 영역에 겹쳐 놓는다. `SetParent`로 임베드하지 않은 이유는 그쪽이
포커스와 크래시 문제를 냈기 때문이다. 창이 진짜 독립 창으로 남아 있어서
입력·포커스·커서가 전부 네이티브로 동작한다.

한글 윈도우에서 새로 띄운 콘솔 창을 찾을 때 PID 매칭이 안 돼서,
창 제목에 ASCII 마커를 박고 `EnumWindows`로 찾는 방식을 쓴다.

## 기능

- 프로젝트 + 도구 + 주제를 골라 새 에이전트 생성, `--continue` / `--resume`으로 이어가기
- 왼쪽 목록에서 단축번호·상태·경과시간 확인, 드래그로 순서 변경
- 오른쪽에 1/2/4 분할 타일로 콘솔 배치
- 단축키: `Ctrl+N` 주제, `Ctrl+Tab` 전환, `Ctrl+1~9` 선택, `Ctrl+W` 종료, `F11` 전체보기
- 폴더·도구 인앱 관리, 최근 주제, 복제, 세션 복구

## 실행

`에이전트 관리.lnk` 실행. 설정은 `console_config.json`과 `projects.json`에 있다.

## 후속

이 앱의 오버레이 방식이 conhost와 계속 충돌해서, ConPTY로 다시 만든 것이
[HELM](https://github.com/breath024/helm)이다. 다만 이 앱에만 있는 기능
(세션 자동 복구 등)이 있어서 지우지 않고 두고 있다.
